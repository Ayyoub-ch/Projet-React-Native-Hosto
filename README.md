# Projet-React-Native-Hosto
Projet React Native autour de la réservation à l'hôpital

Principe: Mise sur Mobile de l'Application de Gestion de Séjour faite en Php Symfony

But: Permettre aux personnels hôspitaliers de pouvoir accéder à l'application depuis leur smartphone, tout en étant synchronisés avec l'application web

Les données et fonctionnalités de cette application sont similaires à Gestion Séjour, seulement l'Administrateur ne peut se connecter sur l'application Mobile
